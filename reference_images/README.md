# Reference images

Put approved uniform / ID-card reference photos here (JPG/PNG), or upload them in
**Uniform & ID** -> *Reference images*.

* Group photo (beige shirts + navy trousers + lanyards): calibration reference for the colour ranges.
* ID-card + lanyard photo: reference for a future custom ID detector.

**Privacy:** the ID-card photo contains a real student's name, photo and enrolment number.
Crop or blur those fields before storing it, and do not commit it to a public repository.
These photos are calibration references, NOT a training set - two photos cannot train a reliable model.
